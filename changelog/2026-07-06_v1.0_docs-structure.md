# Changelog — 2026-07-06 | v1.0 Docs Structure

## Tóm tắt
Khởi tạo cấu trúc tài liệu FRS chuẩn cho dự án OneCRM. Tổ chức lại toàn bộ docs theo module, tạo templates, và viết FRS đầu tiên cho module Contract.

---

## Thay đổi

### Cấu trúc thư mục mới
```
docs/
├── prd/          ← PRD chính thức (.docx)
├── demo/         ← Demo HTML theo module/version
├── frs/          ← FRS tách theo module
│   ├── _templates/
│   ├── customers/
│   └── contracts/
└── flows/        ← Ảnh BPMN từ ChatGPT

changelog/        ← Changelog theo version/date
```

### Files mới
| File | Mô tả |
|------|-------|
| `docs/frs/_templates/frs_template.md` | Template chuẩn cho tất cả FRS |
| `docs/frs/_templates/checklist_frs.md` | Checklist review nghiệp vụ |
| `docs/frs/_templates/checklist_ui.md` | Checklist review UI/UX |
| `docs/frs/customers/UC-CUS-02_create_customer.md` | FRS tạo mới khách hàng (migrate từ file gốc) |
| `docs/frs/contracts/UC-CON-03_view_contract.md` | FRS xem chi tiết hợp đồng — **Draft for Review** |
| `docs/frs/contracts/UC-CON-06_delete_contract.md` | FRS xóa hợp đồng — **Draft for Review** |

### Files rename/reorganize
| Cũ | Mới |
|----|-----|
| `docs/demo_v1.0.html` | `docs/demo/v1.0_login.html` |
| `docs/demo_v2.2.html` | `docs/demo/v2.2.0_customers.html` |
| `docs/demo_v2.3.html` | `docs/demo/v2.2.1_customers.html` |
| `docs/demo_v2.3.2.html` | `docs/demo/v2.3.2_contracts.html` |

### Convention đã chốt
- **File FRS:** `UC-{MOD}-{NN}_{action}_{entity}.md`
- **Demo HTML:** `v{major}.{minor}_{module}.html` — mỗi module tăng 1 major version
- **Module versions:** Customer=v2.2.x · Contract=v2.3.x · Subscription=v2.4.x · ...

## Hướng dẫn cho Dev đọc tài liệu

1. **Đọc PRD tổng quan:** `docs/prd/OneCRM_PRD_v2.3.docx`
2. **Xem demo UI:** `docs/demo/v2.3.2_contracts.html` — mở bằng browser
3. **Đọc FRS từng tính năng:** `docs/frs/contracts/UC-CON-XX_*.md`
4. **Thứ tự implement:** UC-CON-01 → 02 → 03 → 04 → 05 → 06
5. **Mỗi FRS có:** luồng nghiệp vụ, mô tả UI, business rules, acceptance criteria
